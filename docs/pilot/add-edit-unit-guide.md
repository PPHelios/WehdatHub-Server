### Quick Overview / نظرة سريعة

| Feature / الخاصية | Description (English) | الوصف (بالعربية) |
|---|---|---|
| **Add Unit Flow (4 Steps)** | Sequential wizard: Place & Features → Size & Price → Delivery & Payment → Owner & Photos. | معالج منظم من 4 خطوات: المكان والمميزات ← المساحة والسعر ← الاستلام والدفع ← المالك والصور. |
| **New Compound Request** | On-the-spot compound registration with area selection if not found in autocomplete. | طلب وتسجيل كمبوند جديد فورياً مع اختيار المنطقة في حال عدم وجوده بالاقتراحات. |
| **Unified Place Box** | Single search box for compound hierarchy and auto-converting feature chips. | صندوق بحث موحد للكمبوند والمنطقة مع تحويل المميزات إلى رقاقات (chips) قابلة للحذف. |
| **Duplicate Detection** | Smart algorithm flags matching listings before saving to avoid duplicate inventory. | فحص ذكي للتشابه ينبه عند وجود وحدات مكررة بنفس السعر والمساحة لتفادي التكرار. |
| **Natural Language Search** | AI parses conversational text queries into structured database filters. | محرك بحث ذكي يفهم جمل المحادثة العادية ويحولها تلقائياً إلى شروط بحث دقيقة. |
| **Voice Search** | Tap-to-speak hands-free search with automated speech-to-text conversion. | بحث صوتي بنقرة واحدة لتحويل الكلام مباشرة إلى نتائج بحث. |
| **Refine Filters Drawer** | Granular controls for price, size, finishing, furnished, and payment plans. | لوحة فلاتر متقدمة تشمل كافة تفاصيل السعر والمساحة والتشطيب والأقساط. |
| **Data Privacy** | Owner contact numbers are strictly confidential and stripped from public client links. | أرقام الملاك سرية تماماً داخل الوكالة وتُحجب تلقائياً من روابط المشاركة مع العملاء. |
